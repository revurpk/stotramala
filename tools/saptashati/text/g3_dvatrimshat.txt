# Durgā Saptaśatī, appendix: Durgā-dvātriṃśannāmamālā — from the Gita Press Śrīdurgāsaptaśatī
# (Gorakhpur, code 118, pages 223–225); spelling as printed; a speaker line is unnumbered (0).
# @D 0 lines are unnumbered verses; @P lines are prose (nyāsas, mantras).
@H दुर्गाद्वात्रिंशन्नाममाला
@D 0 | दुर्गा दुर्गार्तिशमनी दुर्गापद्विनिवारिणी। | दुर्गमच्छेदिनी दुर्गसाधिनी दुर्गनाशिनी॥
@D 0 | दुर्गतोद्धारिणी दुर्गनिहन्त्री दुर्गमापहा। | दुर्गमज्ञानदा दुर्गदैत्यलोकदवानला॥
@D 0 | दुर्गमा दुर्गमालोका दुर्गमात्मस्वरूपिणी। | दुर्गमार्गप्रदा दुर्गमविद्या दुर्गमाश्रिता॥
@D 0 | दुर्गमज्ञानसंस्थाना दुर्गमध्यानभासिनी। | दुर्गमोहा दुर्गमगा दुर्गमार्थस्वरूपिणी॥
@D 0 | दुर्गमासुरसंहन्त्री दुर्गमायुधधारिणी। | दुर्गमाङ्गी दुर्गमता दुर्गम्या दुर्गमेश्वरी॥
@D 0 | दुर्गभीमा दुर्गभामा दुर्गभा दुर्गदारिणी। | नामावलिमिमां यस्तु दुर्गाया मम मानवः॥ | पठेत् सर्वभयान्मुक्तो भविष्यति न संशयः॥
